# Каталог типов тикетов servicedesk

> **[AI] Документ подготовлен AI-ассистентом** (сохранение диалога, 18 октября 2026).
> Исходный запрос и полный ответ ассистента без редактирования смыслов.

---

## Запрос

Представь что ты крупная корпорация. десятки - сотни тысяч сотрудников, десятки-сотни
миллионов клиентов. бизнес ведете как в оффлайне так и в онлайне. штат специалистов
полностью покрывает все твои потребности в бизнесе и вокруг него. и как у любой
уважающей себя компании у тебя есть единая servicedesk система и по сотрудникам и по
клиентам. задача: собрать максимальное разнообразие видов и типов поступающих тикетов.

---

## Ответ

Отличная задача для распределения классов. Раз у нас «все специалисты в штате» и
гибридный бизнес, servicedesk — это фактически зеркало всей компании. Ниже — максимально
разнообразный каталог с группировкой по аудитории, домену и характеру запроса.

### Модель таксономии

Тикет классифицируется по осям:

- **Аудитория**: сотрудник (B2E) / клиент B2C / клиент B2B / подрядчик-партнёр
- **Домен**: IT, HR, финансы, безопасность, фасилити, ритейл-операции, логистика, юр,
  маркетинг, R&D
- **Характер**: инцидент (сломалось) / запрос (нужно новое) / проблема (есть workaround)
  / change / жалоба / возврат / идея / квиря регулятора
- **Канал**: телефон, чат-бот, мобильное приложение, email, web-форма, магазин (терминал
  кассира), соцсети, письмо, факс(!), walk-up

---

### 1. Сотрудники (B2E) — внутренний helpdesk

#### IT / техника

- Не включается ПК / не загружается ОС
- Медленный ноутбук, «память забита архивами»
- Не работает VPN, «не подключается к 1С»
- Забыл пароль / заблокирован после 3 неудачных попыток
- Просьба поставить лицензию (AutoCAD, Figma, MATLAB)
- Просьба продлить лицензию, которая истекла
- Запрос на новое оборудование (монитор, гарнитура, док-станция)
- Запрос спец-оборудования (термопринтер, RFID-сканер, весы)
- Не печатает на сетевой принтер / застряла бумага в переговорке на 3 этаже
- Не работает кассовый сканер в подсобке
- Сломал телефон (корпоративный), разбил экран
- Ноутбук утонул вместе с кофе / уронили на складе
- Нужен второй ноутбук «для демонстрации клиенту»
- Принтер жует чековую ленту в магазине №147
- Wi-Fi гостевой сети не работает в крыле B
- Просьба развернуть тестовый стенд / виртуалку
- Баг в внутреннем CRM-клиенте (некорректно считает скидку)
- Ошибка в отчёте BI: выручка за вчера дублируется
- Просьба снять ограничение скорости на YouTube для отдела маркетинга
- Просьба дать доступ к папке / базе данных / Confluence-странице
- Нужен новый почтовый ящик для стажёра / удалить ящик уволившегося
- Создать группу в мессенджере новому проекту

#### Информационная безопасность

- Подозрительное письмо: «CEO просит срочно оплатить счёт» (BEC)
- Фишинговая ссылка в рассылке / сообщении в чате
- Сотрудник сам открыл .exe из почты и «что-то установилось»
- Запрос на сертификат ЭП для подписания договоров
- Потерял USB-флешку с данными (обязательный репорт по регламенту)
- Утерял/похитили ноутбук в командировке
- Вирус на общем файловом сервере
- Антивирус ругается на легитимный внутренний софт
- Нарушение политики: сотрудник принёс личный ноутбук в сеть
- Запрос на одобрение нового SaaS-продукта (Shadow IT, кто-то уже оплатил)
- Инцидент: доступ к базе клиентов у сотрудника, которого увольняют завтра
- Фиксация факта публикации данных в открытом доступе (утечка)

#### HR / кадры

- Оформление отпуска, отгула, декрета
- Справка 2-НДФЛ, справка с работы для банка
- Смена фамилии после замужества в системах
- Вопрос по расчёту зарплаты: «не пришла премия» / «ошибка в отпускных»
- Запрос на перенос рабочего места в другой город
- Бирюзовый онбординг: не выданы доступы новичку в первый день
- Запрос на обучение / курс / конференцию
- Участие в опросе вовлечённости: «что делать с низким баллом?»
- Конфликт с руководителем: просьба эскалации в HRBP
- Вопрос по больничному: не продлили в 1С, нет электронного листка
- Самозанятый просит акт и оплату по договору ГПХ
- Стажёр: непонятно, кто куратор, просьба назначить
- Запрос на переоформление рабочего места после травмы (эргономика, спецстул)
- Требуется пропуск для подрядчика на территорию склада

#### Фасилити / офис

- Не работает кондиционер / слишком жарко в переговорке «Сакура»
- Забился туалет на 5 этаже / протечка в потолке над бухгалтерией
- Не открывается дверь на этаж (электронный замок)
- Закончилась вода в кулере / сломался кулер
- Уборка не проводится / после вечеринки нужна уборка срочно
- Сломался турникет, сотрудника не пускает домой
- Заказ канцелярии, картриджей, мерча для стажёров
- Забронировать переговорку на 40 человек + телеком-оборудование
- Ремонт рабочего места после того, как уронили монитор
- Запрос на парковочное место / место для коляски
- Перенос серверной: нужен штатный электрик для прокладки кабеля
- Грызун/насекомые в кафе

#### Финансы / закупки

- Авансовый отчёт: не пробивается чек из такси
- Командировочные: перерасход по гостинице, нужна корректировка
- Просьба оплатить счёт подрядчику срочно (и разбор: почему вчера не оплатили)
- Бухгалтерия просит УПД / акт от поставщика (задерживает оплату)
- Возврат от клиента по безналу: сверка расхождений
- Выдача корпоративной карты новому сотруднику / блокировка потерянной
- Вопрос по курсу валют в утренней конвертации
- Запрос на покупку ПО в обход ИТ (уже 5-й случай за месяц)

#### Юридический отдел

- Проверка договора поставки (эталонный шаблон vs правки контрагента)
- Претензия от клиента: магазин «навязал» ненужную гарантию
- Судебный иск: клиент требует компенсацию морального вреда
- Запрос на обработку персональных данных (152-ФЗ): что можно писать в отзыве
- Проверка рекламной акции на соответствие закону о рекламе
- Запрос NDA для стажёра / подрядчика

#### Логистика / склад / закупки

- Не пришёл товар на магазин, «где фура с холодильниками?»
- Бой товара на складе, требуется акт списания
- Кассир не может принять возврат: «в системе нет этой номенклатуры»
- Ошибка в ТТН, поставщик не примет товар без исправления
- Срочная потребность в топливе для корпоративного автопарка
- Поломка холодильной витрины в магазине: товар размораживается
- Не работает терминал сбора данных на складе

#### Маркетинг / веб

- Баг на сайте: кнопка «В корзину» не работает в Safari
- Клиент жалуется, что баннер акции вводит в заблуждение
- Нужен A/B-тест лендинга, доступы к аналитике
- В соцсетях всплывает негативный тред о бренде: нужен ком-план
- PR-запрос журналиста: комментарий по инциденту с утечкой

### 2. Клиенты (B2C) — внешний servicedesk

#### Омниканальные заказы (e-commerce)

- Где мой заказ? Трек-номер не обновляется 3 дня
- Курьер не приехал в окно доставки, «я ждал 4 часа»
- Доставили не то: вместо 2 кг кофе — 2 упаковки кофейных капсул
- Товар повреждён при доставке (разбитый экран телевизора)
- Просят изменить адрес доставки уже после передачи в службу
- Отмена заказа с возвратом на карту, которая закрыта
- Опоздание доставки «в час» на ключ для арендатора
- Доставка в пункт выдачи: ПВЗ переехал, а на карте старый адрес
- Привезли крупногабаритный холодильник, но не подняли на 9 этаж (спор о границах услуги)
- Заказ «под заказ», срок сдвинули дважды — просят компенсацию

#### Возвраты и гарантия

- Возврат товара надлежащего качества в 14 дней (и спор: вскрытая упаковка)
- Возврат некачественного товара: нужны заключение сервис-центра, нет чека
- Гарантийный ремонт смартфона: отказ «следы влаги» — клиент не согласен
- Обмен на аналогичный: закончились, предлагают доплатить
- Возврат предоплаты по товару, который так и не пришёл
- Возврат денег за неиспользованную доставку Premium

#### Лояльность и подписка

- Не начислили баллы за покупку, чек в приложении
- Сгорели баллы: клиент уверен, что бессрочно
- Отмена подписки: списали деньги после отмены
- Тир «Золото» не повысился, хотя потратил 100к
- Смена привязанного телефона в программе лояльности
- Мошенник спилил баллы: «списали 20 000 баллов в 3 ночи» — фрод-инцидент

#### Платежи и счета (для финансовых клиентов)

- Списание дважды за одну покупку
- Не проходит оплата картой (лимит, 3-D Secure, отказ банка)
- Возврат по чужой карте, спор по операции (чарджбек)
- Начислили пени/штраф — просят пересчитать
- Ошибка в счёте для юрлица-партнёра
- Клиент не получил закрывающие документы по договору

#### Аккаунт и идентичность

- Не приходит SMS-код (оператор, роуминг, номер заблокирован)
- Забыл пароль, восстановление по старому номеру
- Дубль аккаунта после регистрации через Google и телефон
- Удаление аккаунта и данных (GDPR/152-ФЗ) — право на забвение
- Запрос на выгрузку персональных данных
- Подозрение, что аккаунт взломали (сменён email, история заказов чужая)
- Ребёнок совершил покупку с телефона родителя: оспоримая операция

#### Жалобы и НКА (то, что потом уходит в регулятору)

- «Кассир грубит, снял видео»
- Не пробили чек / не выдали товар по чеку
- Цена на полке отличается от цены на кассе (право клиента — по низкой цене)
- Срок годности истёк / товар без маркировки
- Отказ в приёме оплаты наличными свыше лимита
- Жалоба на агрессивного курьера, навязывание доп. услуг
- Конфликт охраны магазина и клиента
- Обращение по телефону горячей линии через уполномоченного
- Повторная жалоба: «в третий раз одно и то же, пишу в Роспотребнадзор»
- Требование видеозаписи с камеры (персональные данные — только по процедуре)
- Антикоррупционная горячая линия: сообщение о взятке сотруднику

#### Поддержка продукта / сервиса

- Как пользоваться функцией в приложении (онбординг)
- Ошибка в приложении: падает на Android 14, скриншот прилагается
- Интеграция API для B2B-партнёра: «не проходит вебхук»
- Настройка терминала эквайринга в магазине партнёра
- Вопрос по документации: как загрузить каталог товара по XML

#### Клиент B2B

- Согласование специальных условий / индивидуального прайса
- Спор по договору: несоответствие объёма поставки
- Требование провести аудит поставщика на нашей стороне
- Претензия по качеству партии: 5% боя, просят компенсацию
- Запрос на отсрочку платежа / изменение графика
- Смена реквизитов юрлица у партнёра (проверка на мошенничество)
- Партнёр просит белый лейбл / совместный маркетинг

#### Клиент физлицо в офлайн-магазине

- Не работает карта лояльности (штрих-код стёрся) — перевыпуск
- Спор с продавцом-консультантом по характеристикам товара
- Клиент оставил вещи в ячейке камеры хранения и не может забрать
- Потерял чек, требует возврат
- Опоздал на акцию «час скидок» и требует скидку

### 3. «Креативные» и краевые тикеты (для покрытия редких классов)

Это самая ценная часть для датасета — на них обычно ломаются классификаторы и боты.

- «Тикет» от неловко сформулированной мысли: *«Здравствуйте. Так вот. Ну. Короче, сама
  не знаю что хочу»*
- Клиент звонит: «Это не срочно, просто хотел поговорить»
- Рекламный бот конкурента, накрутивший негативные отзывы
- Письмо на латинице с кириллицей вперемешку (палиндром запроса)
- Сотрудник ставит тикет от имени коллеги без ведома (spoofing внутренний)
- Запрос, который нарушает закон («оформите мне доступ к базе клиентов, я для себя»)
- Клиент присылает фото кота «заодно»
- Тикет-провокация: проверка, как отвечает ИИ («Сколько будет 2+2? Это тест»)
- Угрозы и нецензурная лексика в теле тикета (класс toxic / нужен эскалейшн)
- Инцидент безопасности, замаскированный под обычный запрос
- Обращение от госоргана / прокуратуры / налоговой — отдельный эскалационный трек
- Обращение СМИ с требованием комментария «до 17:00»
- Сезонная волна: «1С не обновилась после Нового года у 800 сотрудников» — mass-incident
  с групповым тикетом
- Клиент просит вернуть деньги за покупку, сделанную в другом бренде нашей группы
  (ошибся дверью)
- Форс-мажор: стихийное бедствие, доставка в регион не работает, клиенты пишут пачками
- Информационная атака: в соцсетях вирусится фейк «компания закрывается»

### 4. Структура самого тикета (метаданные)

Чтобы разнообразие было не только в тексте, но и в схеме:

| Поле | Примеры значений |
|---|---|
| request_type | incident / request / problem / change / complaint / idea / inquiry / legal / threat |
| channel | app / chat / phone / email / store-terminal / social / letter / fax / api / walk-up |
| priority | P1 (все кассы легли) … P4 (просьба-идея) |
| impact × urgency | массовый / единичный × срочно / в плановом порядке |
| sentiment | агрессия / нейтрал / паника / вина / благодарность |
| language | ru / en / смешанный / авто-перевод |
| pii_present | есть персональные данные → отдельная обработка |
| fraud_score | подозрение на мошенничество |
| regulatory | попадает ли под ФЗ / жалоба в надзорный орган |
| sla_policy | корпоративные 15 мин / розница 2 ч / B2B 1 раб.день |

### Уточняющие вопросы от ассистента

1. **Какая цель?** Обучение классификатора/бота (тогда нужны лейблы и вариации
   формулировок), стресс-тест сервис-деска, редизайн таксономии, генерация тестовых
   данных?
2. **Какая глубина?** Нужен именно список типов или реалистичные примеры тикетов с
   дословными формулировками («грязный» текст от реальных пользователей)?
